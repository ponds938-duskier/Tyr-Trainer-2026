## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Tyr**. This trainer provides convenience and testing options for Tyr's armored vehicle battles, including defensive support, ability cooldown control, ammunition handling, and customization assistance. Use it only in supported local or private environments and disable all modifications before joining public multiplayer matches.

**Target Audience:** Players testing vehicle configurations, learning tank abilities, experimenting with tech-tree upgrades, or practicing in controlled private environments.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Tyr features treaded and hover tanks that require deliberate positioning and defensive angling. Use the trainer only while practicing movement, cover usage, and vehicle handling in a controlled session. Positioning remains important because armor orientation affects how incoming shots are handled.

### Tools & Inventory

Tyr does not use a traditional character inventory. Tank preparation centers on ammunition slots, component upgrades, individual vehicle tech trees, and keystone technology. Use the customization assistance option to test different vehicle configurations before entering a legitimate match.

### World & Environment

Battles take place across tactical multiplayer maps where cover, sightlines, noise, and detection range influence engagements. Vehicles and opponents become visible when within range or when sufficient noise reveals their position. Practice route planning and map awareness without using trainer options in public games.

### Combat & Weapons

Combat rewards patience, teamwork, armor angling, and careful use of each vehicle's unique power. Tanks may blink, reveal enemies with sonar, or overcharge their engines for a damaging ram. Use durability, ammunition, and cooldown options only for private experimentation, then disable them before online play.
